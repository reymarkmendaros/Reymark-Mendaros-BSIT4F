# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are one of the most important cloud infrastructure components because they provide the processing power needed to run applications and services. Without compute resources, other components such as storage and networking would not be able to support active applications effectively. The amount of compute resources can also be adjusted based on workload requirements.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable, flexible, and efficient operating system for servers and virtual machines. It includes powerful command-line tools that allow administrators and cloud engineers to monitor system resources, manage files, configure networks, and troubleshoot problems. Linux is also widely used in cloud environments because of its stability and flexibility.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure design, configurations, resources, and requirements. It helps cloud engineers understand what needs to be deployed and reduces the possibility of mistakes. Good documentation also makes troubleshooting, maintenance, and future improvements easier.

I learned how to investigate a Linux environment using commands such as `lscpu`, `free -h`, `df -h`, `hostname`, and `hostname -I`. I also learned how to identify cloud infrastructure components and compare equivalent services from AWS, Microsoft Azure, and Google Cloud. In addition, I practiced creating technical documentation and organizing project files using GitHub.

My GitHub portfolio improved because I added a complete cloud infrastructure laboratory project with technical documentation, investigation results, screenshots, a cloud architecture diagram, and a cloud provider comparison.
